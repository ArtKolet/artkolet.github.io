# Авторский сайт Алексея Костина

Статический сайт для GitHub Pages. Никакая сторонняя CMS не требуется.

## Как добавить запись в блог

1. Создай Markdown-файл в `content/posts/`, например `novaya-zametka.md`.
2. В начале файла укажи метаданные между двумя строками `---`:

```markdown
---
title: "Название записи"
category: "Наблюдения"
date: "18 октября 2026"
lead: "Короткое вступление для карточки блога."
---

Основной текст записи в Markdown.

## Подзаголовок

Можно использовать **жирный текст**, *курсив*, списки и [ссылки](https://example.com).
```

3. Добавь имя файла (только имя, без пути) в массив `posts` в `content/posts/index.json`, например: `"novaya-zametka.md"`. Новые записи показываются в порядке файлов в этом списке.
4. Сохрани изменения через GitHub кнопкой **Commit changes**. GitHub Pages опубликует обновление автоматически.

Каждая публикация — отдельный `.md` файл. `index.json` — только небольшой список файлов, потому что статический GitHub Pages не умеет автоматически перечислять содержимое папки.

## Портрет

В разделе «Автор» используется одна фотография на всю высоту блока «Обо мне». Замени `images/portrait.jpg` на свой портрет, сохранив это имя файла. Для лучшего результата подойдёт вертикальное фото.

## Структура

- `index.html` — структура страницы
- `css/style.css` — оформление
- `js/main.js` — взаимодействие и загрузка Markdown-записей
- `content/posts/` — отдельные записи блога и `index.json`
- `images/` — портрет, фотографии и обложки
- `books/` — PDF рукописей
