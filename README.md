# Авторский сайт Алексея Костина

## Структура проекта
- `index.html` — разметка страницы
- `css/style.css` — оформление
- `js/main.js` — поведение сайта и пути к обложкам
- `content/posts.json` — тексты блога
- `images/` — портреты, фото и рисунки
- `books/` — PDF-книги
- `admin/` — панель управления Decap CMS

## Замена портрета
Положите фотографию в `images/` под именем `portrait.jpg`. Дополнительный снимок — `portrait-secondary.jpg`.

## GitHub Pages
1. Загрузите содержимое папки в репозиторий GitHub в ветку `main`.
2. В **Settings → Pages** включите публикацию из ветки `main`, папки `/ (root)`.
3. В `admin/config.yml` замените `YOUR_GITHUB_USERNAME/YOUR_REPOSITORY` на владельца и имя репозитория, затем укажите правильный `site_url`.
4. Для входа Decap CMS с GitHub нужен OAuth-провайдер/сервер аутентификации. GitHub Pages — статический хостинг и не обеспечивает серверную авторизацию. Не вставляйте GitHub Personal Access Token в HTML/JavaScript.
5. После настройки OAuth панель будет доступна по адресу `https://ВАШ-АДРЕС/admin/`. Записи блога можно добавлять и редактировать там; сохранения создают коммиты в GitHub.

**Важно:** файлы панели включены, но авторизация требует настройки OAuth. Это необходимо для безопасного доступа и записи изменений в репозиторий.
